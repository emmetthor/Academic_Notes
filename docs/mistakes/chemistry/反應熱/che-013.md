# che-013

## 題目

（原題第 16 題）下列各反應式：

$$
\begin{aligned}
\ce{C2H5OH(l) + 3 O2(g) -> 2 CO2(g) + 3 H2O(l)} &+ Q_1\\
\ce{C2H5OH(l) + 3 O2(g) -> 2 CO2(g) + 3 H2O(g)} &+ Q_2\\
\ce{C2H5OH(g) + 3 O2(g) -> 2 CO2(g) + 3 H2O(l)} &+ Q_3\\
\ce{C2H5OH(g) + 3 O2(g) -> 2 CO2(g) + 3 H2O(g)} &+ Q_4
\end{aligned}
$$

其中 $Q_1$、$Q_2$、$Q_3$、$Q_4$ 為熱量，則熱量大小關係哪些正確？

- (A) $Q_2 > Q_4$
- (B) $Q_4 > Q_1$
- (C) $Q_1 > Q_2$
- (D) $Q_3 > Q_2$
- (E) $Q_3 > Q_4$

## 解法

**答案：(C)、(D)、(E)。**

熱量寫在產物側，因此 $Q_i$ 表示放出的熱量，與反應焓變的關係為 $\Delta H_i=-Q_i$。同一物質的氣態焓高於液態焓；反應物焓越高或產物焓越低，放熱量越大。

令乙醇與水的莫耳汽化熱分別為 $L_{\mathrm{EtOH}}>0$、$L_{\mathrm{H_2O}}>0$，則：

$$
\begin{aligned}
Q_1-Q_2&=3L_{\mathrm{H_2O}}>0,\\
Q_3-Q_4&=3L_{\mathrm{H_2O}}>0,\\
Q_3-Q_1&=L_{\mathrm{EtOH}}>0,\\
Q_4-Q_2&=L_{\mathrm{EtOH}}>0.
\end{aligned}
$$

因此 (A) 錯誤，(C)、(E) 正確；又因為 $Q_3>Q_1>Q_2$，所以 (D) 正確。

比較 (B) 時，反應物與產物的物態同時改變，必須比較汽化熱：

$$
Q_4-Q_1=L_{\mathrm{EtOH}}-3L_{\mathrm{H_2O}}.
$$

常溫下乙醇的莫耳汽化熱約為 $42\ \mathrm{kJ\,mol^{-1}}$，水約為 $44\ \mathrm{kJ\,mol^{-1}}$，所以 $Q_4<Q_1$，(B) 錯誤。僅由「氣態焓高於液態焓」本身，不能直接判定這一組的大小。

比較熱量時，要注意題目的 $Q$ 是放熱量，不能直接當成帶負號的 $\Delta H$。
