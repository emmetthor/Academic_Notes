# che-010

## 題目

下列何者在反應中只能作還原劑，而不能作為氧化劑？

(A) $\mathrm{H_2S}$

(B) $\mathrm{KMnO_4}$

(C) $\mathrm{H_2O_2}$

(D) $\mathrm{SO_2}$

(E) $\mathrm{KNO_2}$

## 解法

::: details

答案為 **(A)**。

還原劑失去電子，本身被氧化，氧化數上升；氧化劑得到電子，本身被還原，氧化數下降。本題依高中常見反應中主要變價元素的氧化數判斷。

- (A) $\mathrm{H_2S}$ 中硫為 $-2$，已是硫的最低常見氧化數，只能再被氧化，因此作還原劑。
- (B) $\mathrm{KMnO_4}$ 中錳為 $+7$，可被還原，常作氧化劑。
- (C) $\mathrm{H_2O_2}$ 中氧為 $-1$，可下降至 $-2$，也可上升至 $0$，因此兼具氧化劑與還原劑的性質。
- (D) $\mathrm{SO_2}$ 中硫為 $+4$，可上升至 $+6$，也可下降至 $0$ 或 $-2$，因此兩者皆可。
- (E) $\mathrm{KNO_2}$ 中氮為 $+3$，可上升至 $+5$，也可被還原至較低氧化數，因此兩者皆可。

例如，過氧化氫作氧化劑時，氧由 $-1$ 降至 $-2$：

$$
\mathrm{H_2O_2 + 2H^+ + 2e^- \rightarrow 2H_2O}
$$

作還原劑時，氧由 $-1$ 升至 $0$：

$$
\mathrm{H_2O_2 \rightarrow O_2 + 2H^+ + 2e^-}
$$

:::
