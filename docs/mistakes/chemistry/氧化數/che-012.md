# che-012

## 題目

下列各元素可能發生的氧化數，何者錯誤？

(A) 氧的氧化數為 $-\dfrac{1}{2}$

(B) 氟的氧化數 $+1$

(C) 鈉的氧化數為 $0$

(D) 氯的氧化數為 $+7$

(E) 氫的氧化數為 $-1$

## 解法

::: details

答案為 **(B)**。

- (A) 正確。超氧化物如 $\mathrm{KO_2}$ 中，鉀為 $+1$，故兩個氧的氧化數總和為 $-1$，氧的平均氧化數為 $-\dfrac{1}{2}$。
- (B) 錯誤。氟的電負度最大，在化合物中氧化數為 $-1$；在元素態 $\mathrm{F_2}$ 中為 $0$，不會是 $+1$。
- (C) 正確。元素態的氧化數為 $0$，例如金屬鈉 $\mathrm{Na}$。不能將化合物中鈉通常為 $+1$ 的規則套用到元素態。
- (D) 正確。例如 $\mathrm{HClO_4}$ 中，$(+1) + x + 4(-2) = 0$，解得氯的氧化數 $x = +7$。
- (E) 正確。在金屬氫化物如 $\mathrm{NaH}$ 中，鈉為 $+1$，氫為 $-1$。

判斷時先區分元素態與化合物，再注意超氧化物、金屬氫化物等例外。

:::
