# che-009

## 題目

關於物質純化與分離的敘述，下列哪些正確？（應選二項）

(A) 利用再結晶純化硝酸鉀，以水為溶劑會比汽油較為合適

(B) 硫酸銅晶體可由飽和的藍色硫酸銅水溶液中結晶獲得

(C) 將食鹽水加熱，蒸餾出部分純水，而剩餘的溶液可再結晶獲得氯化鈉

(D) 利用乙酸乙酯萃取綠色樹葉的萃取液，然後在一大氣壓下進行蒸餾分離，可以將葉綠素餾出

(E) 硝酸鉀與氯化鉀的混合水溶液，可以用濾紙層析方法將兩者分離

## 解法

::: details

答案為 **(A)、(B)**。

- (A) 正確。硝酸鉀是離子化合物，在水中的溶解度會隨溫度明顯改變，水適合作為再結晶溶劑；汽油為非極性溶劑，不適合溶解硝酸鉀。
- (B) 正確。使飽和硫酸銅水溶液冷卻或蒸發部分水分，可析出硫酸銅晶體。
- (C) 錯誤。蒸餾後剩餘溶液取得氯化鈉屬於蒸發結晶，並非題目所稱的再結晶純化。
- (D) 錯誤。蒸餾時餾出的是揮發性較高的乙酸乙酯，葉綠素不會被餾出。
- (E) 錯誤。硝酸鉀與氯化鉀皆為無色、易溶於水的離子化合物，不能用一般濾紙層析有效分離。

:::
