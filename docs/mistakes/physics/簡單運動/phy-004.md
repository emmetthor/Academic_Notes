# phy-004

## 題目

有關運動學的敘述，下列哪些錯誤？（多選）

- (A) 瞬時加速度的方向一定與瞬時速度的方向相同
- (B) 等速率運動必為直線運動
- (C) 在直線運動中，$\dfrac{\text{初速}+\text{末速}}{2}=\text{平均速度}$
- (D) 在等速度運動中，任一瞬間的瞬時速度等於全程的平均速度
- (E) 在等速率運動中，瞬時速率等於平均速率。

## 解法

::: details 解答與解析

**答案：(A)、(B)、(C)。注意題目問的是「錯誤」的敘述。**

- **(A) 錯誤：** 加速度描述速度的變化，其方向不一定與速度相同。例如物體沿直線減速時，加速度與速度方向相反；等速率圓周運動中，兩者方向互相垂直。
- **(B) 錯誤：** 速率固定不代表運動方向固定。等速率圓周運動就是速率固定的曲線運動。
- **(C) 錯誤：** 直線運動不保證加速度固定，故初、末速度的算術平均不一定等於平均速度。等加速度直線運動才保證可用此公式。
- **(D) 正確：** 等速度運動的速度大小與方向都不變，故任一瞬間的速度都等於全程平均速度。
- **(E) 正確：** 等速率運動中，若固定速率為 $v$，則總路程為 $v\Delta t$，因此平均速率也是 $v$。

以 (C) 為例，物體沿同一直線同方向運動，前 $1\ \mathrm{s}$ 以 $1\ \mathrm{m/s}$ 等速行進，接著 $1\ \mathrm{s}$ 等加速至 $3\ \mathrm{m/s}$，則

$$
\bar v=\frac{1\times1+\frac{1+3}{2}\times1}{2}
=1.5\ \mathrm{m/s},
$$

但初、末速度的算術平均為

$$
\frac{v_0+v_f}{2}=\frac{1+3}{2}=2\ \mathrm{m/s}.
$$

兩者不同，足以說明只給「直線運動」的條件並不足夠。

:::
