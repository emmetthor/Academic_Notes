# bio-009

## 題目

有關有絲分裂和減數分裂的敘述，下列何者正確？

(A) 有絲分裂會出現紡錘絲，但減數分裂則無

(B) 在分裂過程中，兩者都會發生同源染色體配對的現象

(C) 單細胞生物體不會發生減數分裂，多細胞生物體則有行減數分裂的潛能

(D) 這兩種分裂的方式是原核生物及真核生物體共同具有的生命現象

(E) 減數分裂使生物體親代與子代的體細胞染色體數目相同

## 解法

::: details

答案為 **(E)**。

- (A) 錯誤。有絲分裂與減數分裂皆會出現紡錘絲。
- (B) 錯誤。同源染色體配對發生於減數分裂第一次分裂前期，有絲分裂不會發生。
- (C) 錯誤。部分單細胞真核生物也能進行減數分裂；並非所有多細胞生物都具有減數分裂的能力。
- (D) 錯誤。有絲分裂與減數分裂是真核生物的細胞分裂方式；原核生物主要以二分裂繁殖。
- (E) 正確。減數分裂使配子的染色體數目減半，受精時再恢復為二倍體，因而使親代與子代的體細胞染色體數目維持相同。

:::
