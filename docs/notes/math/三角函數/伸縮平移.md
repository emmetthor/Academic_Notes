# 伸縮平移

| 操作 | 對函數影響 |
| --- | --- |
| 不變 | $y = \sin(ax - b) + h$ |
| 左移 $k$ | $y = \sin(ax - b + k) + h$ |
| 右移 $k$ | $y = \sin(ax - b - k) + h$ |
| 上移 $k$ | $y = \sin(ax - b) + h + k$ |
| 下移 $k$ | $y = \sin(ax - b + k) + h - k$ |
| 壓縮 $k$ 倍 | $y = \sin(kax - b) + h$ |
| 放大 $k$ 倍 | $y = \sin(\frac{ax}{k} - b) + h$ |

::: tip 伸縮平移的處理

伸縮平移的對象都是 $x$ 本身，因此其他常數是不會被伸縮平移影響的。

:::
