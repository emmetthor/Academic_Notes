# 細胞學史

## 虎克

1. 《微物圖誌》作者。
2. 發現軟木塞中的死細胞壁。

## 雷文霍克

1. **微生物學之父**。
2. 觀察細菌、血球......。

## 布朗

發現**細胞核**。

## 許來登

1. 植物學家。
2. 提出**所有植物細胞都有細胞核**。
3. 提出**所有植物皆由細胞組成**。
4. 認為細胞是由細胞核開始結晶形成。

## 許旺

1. 動物學家。
2. 提出**所有動物細胞都有細胞核**。
3. 提出**所有動物皆由細胞與其產物組成**。
4. 認為代謝是所有細胞的共通現象。

## 魏修

1. **細胞病理學之父**。
2. 認為**所有細胞皆由已存在的細胞產生**。

## 巴斯德

1. **微生物學之父**。
2. 酒精發酵與乳酸發酵。
3. 鵝頸瓶 => 證明「**生源論**」（生物必由生物產生）。

## 弗萊明

1. 發現可染色的染色質。
2. 描述有絲分裂。
