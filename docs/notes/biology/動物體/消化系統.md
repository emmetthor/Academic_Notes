# 消化系統

## 消化系統類型

1. 物理消化幫助化學消化（有酵素）。
2. 胞外消化（酵素在細胞外）與胞內消化（食泡結合溶體）。
3. 囊狀消化腔（一個開口）與管狀消化腔（兩個開口）。

## 人體消化系統

### 消化道構造

由外到內依序如下：

1. 漿膜層：結締組織 + 漿液以防止磨損。
2. 肌肉層：平滑肌，並有環狀（環狀收縮擠壓）與縱向（縱向縮短）肌肉。
3. 黏膜下層：血管 + 神經 + 淋巴管。
4. 黏膜層：柱狀上皮組織 + 腺體。

### 消化道上的括約肌

```text
口 -> 咽 ->（上食道）-> 食道 ->（賁門）-> 胃 ->（幽門）-> 小腸 ->（迴盲瓣）->大腸 -> 肛門 ->（肛門）
```

::: info 迴盲瓣

由於小腸與大腸組成如下：

```text
十二指腸 -> 空腸 -> 迴腸 -> （瓣膜）-> 盲腸 -> 結腸 -> 直腸
```

因此此瓣膜就是**迴**腸 + **盲**腸 中的 **瓣** 膜。

:::
