# 消化系統

## 消化系統類型

1. 物理消化幫助化學消化（有酵素）。
2. 胞外消化（酵素在細胞外）與胞內消化（食泡結合溶體）。
3. 囊狀消化腔（一個開口）與管狀消化腔（兩個開口）。

## 人體消化系統

### 消化道構造

由外到內依序如下：

1. 漿膜層：結締組織 + 漿液以防止磨損。
2. 肌肉層：平滑肌，並有環狀（環狀收縮擠壓）與縱向（縱向縮短）肌肉。
3. 黏膜下層：血管 + 神經 + 淋巴管。
4. 黏膜層：柱狀上皮組織 + 腺體。

### 消化道上的括約肌

![括約肌英文](https://lh4.googleusercontent.com/-sKHDLLtgTmE/UvsMXiWWc9I/AAAAAAAAUp4/nC7oLKGgo6I/s640/gi_system1304998637690.jpg)

```text
口 -> 咽 ->（上食道）-> 食道 ->（賁門）-> 胃 ->（幽門）-> 小腸 ->（迴盲瓣）->大腸 -> 肛門 ->（肛門）
```

::: info 迴盲瓣

由於小腸與大腸組成如下：

```text
十二指腸 -> 空腸 -> 迴腸 -> （瓣膜）-> 盲腸 -> 結腸 -> 直腸
```

因此此瓣膜就是**迴**腸 + **盲**腸 中的 **瓣** 膜。

:::

| 消化道 | 消化腺 | 物理消化 | 化學消化 | 吸收 | 功能 |
| --- | --- | --- | --- | --- | --- |
| 口腔 | 唾腺 | 咀嚼 | 唾液澱粉酶 + 溶菌酶 | | 澱粉，肝醣 -> 葡萄糖，殺菌 |
| 咽 | | | | | 十字路口 |
| 食道 | | | | | 蠕動：下推食團 |
| 胃 | 胃腺 | 外縱中環內斜的肌肉 | 胃蛋白酶 + 鹽酸 | 20%酒精 + 藥物 | 活化胃蛋白酶，蛋白質變性 |
| 小腸 | 腸液、胰液、膽汁 | 分節運動 | 澱粉酶、蛋白酶、脂酶、核酸酶、雙醣酶、肽酶、核苷酸酶 | 養分 + 水 | 主要消化場所 |
| 大腸 | | | | 水分 | 共生菌產生維生素 B, K |

#### 唾腺

- 包含唾液澱粉酶，黏液，溶菌酶。
- 分解澱粉、肝醣變成葡萄糖。
- 殺菌。

#### 胃腺

- 包含胃蛋白酶原、鹽酸、黏液。
- $胃蛋白酶原 \xrightarrow{\ce{H+}} 胃蛋白酶$
- $蛋白質 \xrightarrow{胃蛋白酶} 多肽$ 。

::: info 避免自我腐蝕方式：

1. 黏膜保護。
2. 上皮細胞緊密連結。
3. $\ce{HCO3-}$ 中和。
4. 有胃蛋白酶原消耗 $\ce{H+}$。

:::

#### 肝臟

- 生產膽汁並儲存於膽囊中。
- 膽囊僅排出並非分泌膽汁。

| 名稱 | 功能 |
| --- | --- |
| 膽鹽 | 乳化脂肪，增加表面積，物理消化 |
| 膽色素 | 血紅素代謝產物 |
| $\ce{NaHCO3}$ | 中和酸性 |

#### 胰臟

- 分泌胰液

| 名稱 | 功能 |
| --- | --- |
| 胰澱粉酶 | $澱粉、肝醣 \rightarrow 麥芽糖$ |
| 胰蛋白酶 | $蛋白質、多肽 \rightarrow 更小肽類$ |
| 胰脂酶 | $脂質 \rightarrow 單酸甘油酯 + 脂肪酸$ |
| 胰核酸酶 | $核酸 \rightarrow 核苷酸$ |
| $\ce{NaHCO3}$ | 中和酸性 |

::: info 單酸甘油酯

三酸甘油酯原有三隻腳（三個脂肪酸鏈），經過分解後會變成一隻腳 + 兩個游離脂肪酸，也就是單酸甘油酯。

:::

#### 小腸腺

- 分泌腸液。

| 名稱 | 功能 |
| --- | --- |
| 腸乳糖酶 | $乳糖 \rightarrow 葡萄糖 + 半乳糖$ |
| 腸蔗糖酶 | $蔗糖 \rightarrow 葡萄糖 + 果糖$ |
| 腸麥芽糖酶 | $麥芽糖 \rightarrow 葡萄糖 + 葡萄糖$ |
| 腸肽酶 | $肽類 \rightarrow 胺基酸$ |
| 腸核苷酸酶 | $核苷酸 \rightarrow 五碳醣 + 含氮鹼基 + 磷酸根$ |
| $\ce{NaHCO3}$ | 中和酸性 |
