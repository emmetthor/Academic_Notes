# 更難的方程式求解

## 向量與線性組合

一個化學式可以看成是多維的向量，例如以下題目：

::: info 題目

請以：

$$
\begin{aligned}
\mathrm{I}:\quad &\ce{3 Fe2O3(s) + CO(g) -> 2 Fe3O4(s) + CO2(g)}
&&\Delta H_1\\
\mathrm{II}:\quad &\ce{Fe(s) + CO2(g) -> FeO(s) + CO(g)}
&&\Delta H_2\\
\mathrm{III}:\quad &\ce{Fe3O4(s) + CO(g) -> 3 FeO(s) + CO2(g)}
&&\Delta H_3
\end{aligned}
$$

求出下列化學式的反應熱：

$$
\ce{3 CO(g) + Fe2O3(s) -> 2 Fe(s) + 3 CO2(g)}
$$

:::

可以把化學式看成「反應物消耗 -> 生成物產生」，因此，若以向量 $(\ce{Fe2O3, CO, Fe3O4, CO2, Fe, FeO})$ 表示上述化學式，可以寫成：

$$
\begin{aligned}
\mathrm{I}:\quad &(-3, -1, +2, +1, 0, 0)\\
\mathrm{II}:\quad &(0, +1, 0, -1, -1, +1)\\
\mathrm{III}:\quad &(0, -1, -1, +1, 0, +3)\\
\end{aligned}
$$

與要求出的結果：

$$
(-1, -3, 0, +3, +2, 0)
$$

再來，假設上述化學式可以湊成結果化學式，可以給上述化學式乘上未知常數，也就是：

$$
\begin{aligned}
\mathrm{I}:\quad &x(-3, -1, +2, +1, 0, 0)\\
\mathrm{II}:\quad &y(0, +1, 0, -1, -1, +1)\\
\mathrm{III}:\quad &z(0, -1, -1, +1, 0, +3)\\
\end{aligned}
$$

因此，可以依照每個維度列出方程式：

$$
\begin{cases}
\ce{Fe2O3}: \quad & -3x + 0 + 0 = -1\\
\ce{CO}: \quad    & -x + y - z = -3\\
\ce{Fe3O4}: \quad & 2x + 0 - z = 0\\
\ce{CO2}: \quad   & x - y + z = +3\\
\ce{Fe}: \quad    & 0 - y + 0 = +2\\
\ce{FeO}: \quad   & 0 + y + 3z = 0\\
\end{cases}
$$

透過 $-3x + 0 + 0 = -1, 0 - y + 0 = +2, 0 + y + z = 0$ 就可以解出 $x = \frac{1}{3}, y = -2, z = \frac{2}{3}$。
