# 氧化數

## 介紹

氧化數是判斷氧化還原反應的工具，其口決是：`0 電 1 2 3 氟 氫 氧`。

氧化數實際上是一種假設，若所有電子都跑到電負度高的原子去，那每個原子的電荷會是多少。

氧化數可以幫助判斷氧化還原反應式中，究竟是哪些原子被氧化，哪些被還原。

### 含意

- `0`：元素不帶電，因此氧化數為 `0`。
- `電`：帶電物質的氧化數就是其電量。
- `1`：代表 1A 族，也就是，1A 族的氧化數是 `+1`。
- `2`：代表 2A 族，也就是，2A 族的氧化數是 `+2`。
- `3`：代表 3A 族，也就是，3A 族的氧化數是 `+3`。
- `氟`：F 的氧化數是 `-1`。
- `氫`：H 的氧化數是 `+1`。
- `氧`：O 的氧化數是 `-2`。

## 氧化數平衡法

氧化數平衡法有以下幾個步驟：

1. 找出氧化數有變化的原子。
2. 用原子不滅平衡這些原子。
3. 標示氧化數變化量。
4. 調整係數使氧化數變化量相等。
5. 加入 $\ce{H+}$ 或 $\ce{OH-}$ 以維持電荷平衡。
6. 加入 $\ce{H2O}$ 以維持 $\ce{H}$ 平衡。
7. 檢查。

::: tip 注意

氧化數是「一個」原子的得失電子模擬，因此若反應物的原子個數係數大於一，氧化數也要乘以係數。

:::

## 半反應平衡法

氧化還原反應通常由兩組物質的氧化與還原形成，因此可以將兩組物質分別使用氧化數平衡法，再平衡得失電子。

## 原子的氧化數上下限

氧化數由原子的價電子數決定。因此若是 $n$ A 族，則可能的氧化數 $x$ 範圍是：

$$
n - 8 \le x \le n
$$

:: tip 氟的氧化數

由於氟的電負度最大，因此氧化數只有可能是 -1（化合物）與 0（元素）。

:::
