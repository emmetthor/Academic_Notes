# 因次分析

因次分析可以快速判斷公式正確性，更可以用指定參數猜測轉換公式。

## 基本量與導出量

存在七個基本量：

| 基本量 | SI制單位 | 因次表示 |
| --- | --- | --- |
| 質量 | kg | $\text{M}$ |
| 長度 | m | $\text{L}$ |
| 時間 | s | $\text{T}$ |
| 電流 | A | $\text{I}$ |
| 溫度 | K | $\Theta$ |
| 物質量 | mol | $\text{N}$ |
| 光強度 | cd | $\text{J}$ |

而導出量就是從基本量運算得出的量。

以下是一些特例（無因次量）：

| 物理量 | 公式 |
| --- | --- |
| 比重 | $SG_{true} = \frac{D_{\text{material}}}{D_{\text{water}}}$ |
| 弧度 | $\theta = \frac{\text{arc length}}{\text{radius}}$ |
| 馬赫數 | $M = \frac{V_{\text{sample}}}{V_{\text{sound}}}$ |
| 折射率 | $n = \frac{c}{V_{\text{sample}}}$ |
| 摩擦係數 | 測量得出 |
