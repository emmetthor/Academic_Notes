# 位移、速度與加速度

## 位移與路徑長

| | 位移 | 路徑長 |
| --- | --- | --- |
| 定義 | 位移 $\Delta x$ = 末位置 $x$ - 初位置 $x_0$ | 運動軌跡的總長度 |
| 量 | 向量，如 3m，向右 | 純量 |

因此，若位移是 $\Delta x$，路徑長是 $l$，則：

$$
l \ge | \Delta x |
$$

而 $l = | \Delta x |$ 滿足於「直線運動、且不折返」的情況。

## 速度與速率

| | 速度 | 速率 |
| --- | --- | --- |
| 一段時距 | $\overline{v} = \frac{\Delta x}{\Delta t}$ | $\overline{v_s} = \frac{l}{\Delta t}$ |
| 極短時距 | $v = \lim_{\Delta t \rightarrow 0} \frac{\Delta x}{\Delta t}$ | $v_s = \lim_{\Delta t \rightarrow 0} \frac{l}{\Delta t}$ |
| 量 | 向量 | 純量 |

## 加速度

| | 加速度 |
| --- | --- |
| 一段時距 | $\overline{a} = \frac{\Delta v}{\Delta t}$ |
| 極短時距 | $a = \lim_{\Delta t \rightarrow 0} \frac{\Delta v}{\Delta t}$ |
| 量 | 向量 |

## x - t 圖

| | 割線斜率 | 切線斜率 |
| --- | --- | --- |
| 物理意義 | 割線與 x - t 圖的兩交點 $P, Q$，則 $m = \frac{x_2 - x_1}{t_2 - t_1} = \frac{\Delta x}{\Delta t} = \overline{v}$ | 若 $P, Q$ 距離極度接近，則 $m = \lim_{\Delta t \rightarrow 0} \frac{\Delta x}{\Delta t} = v$ |

## v - t 圖

| | 割線斜率 | 切線斜率 |
| --- | --- | --- |
| 物理意義 | 割線與 x - t 圖的兩交點 $P, Q$，則 $m = \frac{v_2 - v_1}{t_2 - t_1} = \frac{\Delta v}{\Delta t} = \overline{a}$ | 若 $P, Q$ 距離極度接近，則 $m = \lim_{\Delta t \rightarrow 0} \frac{\Delta v}{\Delta t} = a$ |

### v - t 圖的面積

若考慮等速直線運動可知，$v = \frac{\Delta x}{\Delta t}$，故 $\Delta x = vt$，也就是這塊長方形的面積。

倘若把 v - t 圖中的 $t_1 \sim t_2$區域，切成 $\Delta t \rightarrow 0$ 的小塊，則會發現 $\Delta x \rightarrow 0$，可以把每一塊都當成長方形計算，因此：

$$
x(t_2) - x(t_1) = \sum_{i=1}^{\infty} \Delta t_i \times v(t_1 + \Delta t) = \int_{t1}^{t2} v(t) \; dt
$$
