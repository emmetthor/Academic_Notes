# 地質年代與定年法

研究岩層與化石時，可以用兩種方式描述年代：

- **相對年代**：判斷地質事件發生的先後順序，不能得知確切年齡。
- **絕對年代**：利用放射性元素定年，以數值表示岩石或事件的年齡。

## 相對年代

相對定年的基本觀念是**均變說**：「現在是了解過去的鑰匙。」也就是利用今日可觀察到的地質作用，推論過去的地質現象。

### 判斷原則

1. **疊置定律**：未受擾動的沉積岩層中，下方岩層較老，上方岩層較新。
2. **截切定律**：斷層或侵入岩若切過其他岩層，截切者的年代較新。
3. **包裹體定律**：岩石中的礫石或岩塊，年代比包裹它的岩石老。
4. **化石連續定律**：生物化石會依固定順序出現；含有相同化石群的岩層，年代大致相同。

::: info 判讀順序
先依疊置定律排列岩層，再用截切關係判斷斷層與侵入岩的先後；若岩層曾倒轉、褶皺或受到侵蝕，便不能只看上下位置。
:::

### 標準化石

可用來比對岩層年代的化石稱為**標準化石**。

適合作為標準化石的生物通常具有下列特徵：

1. 演化速度快。
2. 生存時限短。
3. 地理分布廣。
4. 數量多且特徵明顯，容易辨認。

| 地質時代 | 常見標準化石 |
| --- | --- |
| 古生代 | 三葉蟲、筆石 |
| 中生代 | 菊石、恐龍 |
| 新生代 | 哺乳類、超微化石 |

### 指相化石

能指出生物生存環境與沉積環境的化石稱為**指相化石**。例如珊瑚通常代表溫暖、清澈的淺海環境；三葉蟲、腕足類、菊石與部分超微化石則可作為海相環境的證據。

::: info 標準化石與指相化石
**標準化石看年代，指相化石看環境。**前者重視生存時間短、分布廣；後者重視生物對環境的適應範圍。
:::

## 放射性元素定年

放射性元素會以固定速率衰變。原有的放射性核種稱為**母元素**，衰變後形成的核種稱為**子元素**。隨時間增加，母元素逐漸減少，子元素逐漸增加。

### 半衰期

母元素數量減少為原來一半所需的時間稱為**半衰期**。經過 $n$ 個半衰期後，母元素的剩餘比例為：

$$
\left(\frac{1}{2}\right)^n
$$

若半衰期為 $T_{1/2}$，經過時間為 $t$，則：

$$
n=\frac{t}{T_{1/2}}
$$

| 定年法 | 約略適用年代 | 常見材料 |
| --- | --- | --- |
| 鈾－鉛法 | 百萬年至數十億年 | 含鈾礦物，如鋯石 |
| 鉀－氬法 | 數十萬年至數十億年 | 雲母、角閃石及火山岩 |
| 銣－鍶法 | 千萬年至數十億年 | 長石等含銣礦物 |
| 碳－14 法 | 約 100～60,000 年 | 木材、骨骼等含碳有機物 |

::: info 如何選擇定年法？
年代越久遠，通常要選擇半衰期越長的核種；年代較近，則選擇半衰期較短的核種。碳－14 法只能測定曾與環境交換碳的生物遺體，不能直接測定古老岩石。
:::

### 適用條件與限制

1. 樣本中必須含有足量且可測量的放射性元素。
2. 礦物形成後須維持**封閉系統**，母、子元素沒有明顯進出。
3. 年代若超過約十個半衰期，剩餘母元素太少，誤差會明顯增加。
4. 沉積岩由較老岩石的碎屑組成，通常不能直接用碎屑礦物代表沉積時間；可改測上下火山灰層，或配合化石進行推定。
5. 變質或受熱事件可能使同位素系統重新計時，因此測得的可能是變質年代，而非原岩形成年代。

## 地質年代表

地質年代由大到小可分為：

$$
\text{宙（Eon）}\rightarrow\text{代（Era）}\rightarrow\text{紀（Period）}\rightarrow\text{世（Epoch）}
$$

前寒武紀約占地球歷史的九成；約 **5.41 億年前**進入顯生宙，生物化石開始大量且明顯地出現。

| 宙 | 代 | 紀 | 生物與重要事件 |
| --- | --- | --- | --- |
| 前寒武紀 | 冥古代、太古代、元古代 | — | 地球形成、早期生命出現，大氣氧氣逐漸累積 |
| 顯生宙 | 古生代 | 寒武紀、奧陶紀、志留紀、泥盆紀、石炭紀、二疊紀 | 寒武紀生命大爆發；魚類、兩生類與爬蟲類先後出現；發生前三次大滅絕 |
| 顯生宙 | 中生代 | 三疊紀、侏羅紀、白堊紀 | 爬蟲類與恐龍繁盛，鳥類出現；發生第四、第五次大滅絕 |
| 顯生宙 | 新生代 | 古近紀、新近紀、第四紀 | 哺乳類繁盛，人類出現 |

### 大滅絕

在一段相對短的地質時間內，全球有大量物種消失的事件稱為**大滅絕**。顯生宙中通常將規模最大的五次合稱為「五大滅絕」。

| 次數 | 發生時間 | 主要受影響生物 | 可能原因與結果 |
| --- | --- | --- | --- |
| 第一次 | 奧陶紀末，約 4.44 億年前 | 筆石、腕足類等海洋生物 | 全球降溫、冰河擴張及海平面下降，使淺海棲地大量消失 |
| 第二次 | 泥盆紀晚期，約 3.72～3.59 億年前 | 珊瑚、三葉蟲、甲冑魚等海洋生物 | 海洋缺氧、氣候與海平面改變；是延續較久的一連串滅絕事件 |
| 第三次 | 二疊紀末，約 2.52 億年前 | 三葉蟲完全滅絕，許多海洋與陸生生物消失 | 大規模火山活動造成全球暖化、海洋缺氧與酸化；為五次中規模最大者 |
| 第四次 | 三疊紀末，約 2.01 億年前 | 大量海洋生物及部分陸生爬蟲類 | 大規模火山活動引起氣候與海洋環境劇變；恐龍之後成為陸地優勢動物 |
| 第五次 | 白堊紀末，約 6,600 萬年前 | 非鳥類恐龍、菊石等 | 小行星撞擊揚起大量塵埃，造成陽光減少、氣候劇變與食物鏈崩潰；哺乳類之後快速發展 |

$$
\text{奧陶紀末}\rightarrow\text{泥盆紀晚期}\rightarrow\text{二疊紀末}\rightarrow\text{三疊紀末}\rightarrow\text{白堊紀末}
$$

::: info 記憶方式
依序記成「**奧、泥、二、三、白**」。第三次二疊紀末大滅絕的規模最大；第五次白堊紀末大滅絕則使非鳥類恐龍消失。
:::

::: info 重點整理
相對年代用岩層關係與化石判斷**先後**；絕對年代用放射性元素衰變求出**數值年齡**。兩者互相配合，才能建立完整的地質年代表。
:::
