# 太陽系形成

## 過程

1. 呈現**星雲**狀態，**低溫且密度大**。
2. 因旋轉產生盤狀。
3. 原恆星形成。
4. 微行星形成，這時恆星開始產生**太陽風**，使**岩石、金屬留在近恆星處**，氣體被吹到遠恆星處。
5. 吸積作用產生行星。

::: info 什麼是原恆星？

在恆星開始進行核融合前，由於星雲坍縮導致的**重力位能減少**，且**能量必須守恆**，讓星雲中的粒子**動能增加**，並**使溫度上升**，最終釋放紅外線使人類發現，這個階段的恆星就是原恆星。

:::

::: info 什麼是微行星？

當宇宙塵埃成長至約一公里時，這時其自身重力已經可以把其他類似天體吸引在一起，組成原行星。這個階段的天體就是微行星。

:::
